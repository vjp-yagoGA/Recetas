# Sprint 1 - DWEC


Aplicación de colección de recetas con:
- cabecera con título y resumen
- listado de elementos generados con createElement, textContent y append
- búsqueda por texto en tiempo real
- ordenación por nombre, tiempo y fecha
- resumen con "Mostrando X de Y recetas"
- guardado del último criterio en cookie
- lectura del estado al recargar la página
- fechas legibles y resaltado de elementos recientes
- validación de un campo con expresión regular antes de añadir un elemento
- aviso cuando la búsqueda no devuelve resultados

## Requisitos de uso
1. Abrir la carpeta del proyecto.
2. Ejecutar un servidor local, por ejemplo:
   python -m http.server 8000
3. Abrir http://localhost:8000

## Archivos principales
- index.html
- css/estilos.css
- js/app.js
